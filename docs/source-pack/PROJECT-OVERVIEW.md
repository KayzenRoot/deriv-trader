# Project Overview
Deriv Trader is a greenfield, research-first automated trading project. Initial objective: determine whether objectively validated positive expectancy can be demonstrated for Deriv-compatible contracts using official APIs and rigorous out-of-sample testing.
Current phase: bootstrap/planning. No profitable strategy, production bot, live-money readiness or regulatory suitability is claimed.
Boundaries: market data, research/backtesting, strategy evaluation, risk, broker adapters, execution, observability and audit.
