# Project Overview
Deriv Trader V1 is a deliberately short, research-first automated trading product intended to reach a usable demo/paper validation state quickly while preserving HIGH_ASSURANCE controls.

The user selects exactly one of five strategy profiles. The platform scans all currently eligible instruments, filters by measured payout (default minimum 80%) and broker capability, supports candidate expiries of 1m/3m/5m, applies the selected strategy, then applies global risk and broker-safety gates.

The V1 includes a premium UGAS-produced glassmorphism identity, operator dashboard, configuration/risk center and basic admin panel designed to evolve into a future micro-SaaS.

No strategy profitability, live-money readiness or regulatory suitability is claimed until separately proven.
