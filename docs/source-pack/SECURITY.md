# Security & Financial Safety
Risk: HIGH_ASSURANCE.
Before live trading: secrets isolation; least privilege; demo/live separation; exposure/loss limits; kill switch; idempotency; replay protection where applicable; reconciliation; tamper-evident audit; supply-chain review; rollback/roll-forward; independent exact-head review.
