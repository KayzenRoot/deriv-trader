# V1 Risk Reason Codes

Required machine-readable reasons include:
- DAILY_LOSS_LIMIT_REACHED
- DAILY_TARGET_REACHED
- MAX_SIMULTANEOUS_ORDERS
- MAX_OPEN_EXPOSURE
- MAX_ORDERS_PER_INSTRUMENT
- MAX_CONSECUTIVE_LOSSES
- GLOBAL_COOLDOWN
- INSTRUMENT_COOLDOWN
- OUTSIDE_OPERATING_WINDOW
- ASSET_BLOCKED
- PAYOUT_BELOW_MINIMUM
- PROPOSAL_STALE
- DATA_STALE
- RUNNER_STOPPED
- PAUSE_NEW_ENTRIES
- KILL_SWITCH_ACTIVE
- LOSS_CASCADE_CAUTION
- LOSS_CASCADE_THROTTLED
- LOSS_CASCADE_PAUSED
- BROKER_CAPABILITY_BLOCK
- API_RATE_BUDGET_BLOCK
- IDEMPOTENCY_DUPLICATE

Each block must be visible in audit history and aggregatable in reports.
