# Initial Strategy Pack V1

Five independent strategy families. Users may run multiple validated strategy-expiry Runners concurrently. None is labeled profitable until Deriv-specific OOS/demo evidence exists.

## 1. Trend Pulse — Momentum / Trend Continuation
Follows short directional movement while momentum, persistence and volatility support continuation.
Profiles: 1m / 3m / 5m independently validated.

## 2. Mean Snapback — Short-Horizon Mean Reversion
Looks for statistically stretched moves in range-like conditions and controlled return toward a local mean.
Profiles: 1m / 3m / 5m independently validated.

## 3. Breakout Surge — Compression to Expansion
Detects compressed ranges and directional expansion after a credible break.
Profiles: 1m / 3m / 5m independently validated.

## 4. Anchor Pullback — Trend Pullback to Adaptive Mean
Waits for a controlled pullback in an established trend and enters on validated resumption.
Profiles: 1m / 3m / 5m independently validated.

## 5. Micro Pressure — Tick/Microstructure Pressure
Measures genuine available short-horizon tick/microstructure pressure without claiming full order flow unless the data supports it.
Profiles: 1m / 3m / 5m independently validated.

## Common
A user may start any accepted combination, such as Trend Pulse 1m + Trend Pulse 3m + Breakout Surge 3m. Each combination is a separate Runner. No confluence is required.
