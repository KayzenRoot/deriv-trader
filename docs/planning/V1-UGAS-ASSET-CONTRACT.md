# V1 UGAS Asset Production Contract

## Rule
Original Deriv Trader brand/visual assets are produced through the user's UGAS pipeline.

ChatGPT planning defines briefs/specifications. It must not falsely claim an asset was produced by UGAS unless the UGAS workflow actually generated/approved it.

## Asset groups

### Brand
- primary logo;
- compact mark;
- monochrome variants;
- favicon/app icon;
- safe-area/min-size rules.

### Design tokens
- dark base surfaces;
- glass surfaces;
- borders;
- semantic status colors;
- typography hierarchy;
- spacing/radius/shadow/blur tokens;
- chart token family.

### Interface visuals
- navigation icons;
- strategy family icons;
- Runner status motifs;
- scanner/radar motif;
- risk shield motif;
- connection/account icons;
- empty/error/offline illustrations;
- loading skeleton language.

### Motion
- startup/loading motion;
- scanner pulse;
- Runner starting/running transitions;
- slot reservation/release;
- order lifecycle;
- KPI count-up;
- chart transitions;
- alert entrance;
- success/loss/risk-stop microinteractions.

### Marketing-ready starter assets
Deferred from critical V1 UI but UGAS may prepare:
- social/avatar mark;
- product hero background;
- OG image template;
- landing-page hero motif.

## Deliverable formats
Prefer vector/SVG for logos/icons where practical.
Raster assets include source + optimized web exports.
Design tokens delivered in a machine-readable format compatible with the UI implementation.

## Acceptance
Every asset must pass:
- brand consistency;
- dark-theme readability;
- accessibility/contrast;
- responsive behavior;
- performance/size;
- no licensing ambiguity for third-party source material.
