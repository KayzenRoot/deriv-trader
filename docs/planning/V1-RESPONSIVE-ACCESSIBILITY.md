# V1 Responsive & Accessibility Contract

## Desktop first
Trading operation is optimized primarily for desktop because of information density and multiple simultaneous Runners.

## Tablet
Core monitoring/configuration remains functional with adaptive grid and reduced simultaneous panels.

## Mobile
Mobile supports:
- monitoring;
- Stop All/Kill Switch;
- Runner start/stop when safe;
- order/history review;
- risk status;
- connection/system alerts.

Complex research/admin workflows may be simplified on mobile rather than squeezed into unusable layouts.

## Accessibility
- keyboard navigation for primary controls;
- visible focus states;
- WCAG-aware contrast targets;
- labels/tooltips not dependent only on color;
- reduced-motion preference honored;
- charts have textual summaries/key values;
- critical statuses include icon + text + color;
- touch targets large enough for mobile use.

## Motion
Animations must support prefers-reduced-motion.
No safety-critical state relies on animation to be understood.
