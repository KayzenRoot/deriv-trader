## Dashboard
Purpose: immediate operational + performance overview.
Shows:
- environment;
- Deriv connection;
- active Runners;
- open order slots;
- daily PnL;
- risk state;
- scanner/API health;
- primary KPI cards;
- key charts;
- recent orders/signals/alerts.

## Scanner
Purpose: inspect current market universe.
Shows:
- eligible/ineligible instruments;
- current payout;
- supported expiries;
- freshness;
- active Runner demand;
- reason for exclusion;
- filters/search.

## Strategies
Purpose: configure and operate Runners.
Shows:
- five strategy families;
- plain-language descriptions;
- 1m/3m/5m validated profiles;
- Start/Stop individual Runner;
- Start Selected / Start All / Stop All;
- live Runner metrics.
