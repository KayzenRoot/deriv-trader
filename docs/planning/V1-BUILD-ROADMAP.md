# V1 Short Build Roadmap

Principle: smallest sequence that produces a credible, testable demo product.

1. DT-UX-0001 — UGAS identity/design system and core screen mockups.
2. DT-ARCH-0001 — freeze runtime stack, data model and service boundaries.
3. DT-API-0001 — public Deriv adapter, active symbols, ticks, proposal/capability contracts, pacing/backoff.
4. DT-DATA-0001 — provenance-first market/proposal capture and replay fixtures.
5. DT-RISK-0001 — configurable global risk engine.
6. DT-STRAT-0001 — five independent strategy specifications + test harness.
7. DT-SCANNER-0001 — all-eligible-instrument scanner + Payout Pulse Scheduler.
8. DT-EXEC-DEMO-0001 — demo execution, idempotency and reconciliation.
9. DT-DASH-0001 — operator dashboard, settings/risk UX and strategy selection.
10. DT-ADMIN-0001 — basic admin/SaaS-ready foundation.
11. DT-V1-INTEGRATION-0001 — end-to-end integration, performance, security and regression.
12. DT-V1-ACCEPTANCE-0001 — exact-head acceptance, demo evidence and release checkpoint.

Parallelizable after architecture freeze: UX, risk, data capture and admin shell. Trading strategy acceptance remains independent per strategy.
