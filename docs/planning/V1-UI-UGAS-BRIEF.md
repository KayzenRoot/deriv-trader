# V1 UI / UGAS Visual Brief

All original visual identity and visual assets for Deriv Trader are to be produced through the UGAS pipeline.

## Brand direction
Technological, elegant, premium, controlled, precise. Glassmorphism with strong readability, restrained depth, fine borders, soft blur, high information density without visual noise.

## Required UGAS deliverables
- Deriv Trader logo system: primary, compact mark, monochrome, app/favicon;
- palette tokens for dark-first UI plus accessible semantic states;
- typography pairing and hierarchy;
- icon language;
- background/texture system;
- glass card treatment;
- chart/market visualization language;
- strategy-card visuals;
- loading/empty/error/success states;
- admin visual language;
- future landing-page starter assets.

## Core screens to design
1. Sign-in/onboarding shell (future SaaS-ready).
2. Overview dashboard.
3. Market Scanner.
4. Strategy Selection.
5. Strategy Detail.
6. Orders / Positions.
7. History & Analytics.
8. Risk Center.
9. Settings.
10. Admin Panel.
11. System Health / Audit.

## UX rule
Beauty must never obscure trading state. Payout, selected strategy, expiry, risk status, demo/live state, stop conditions and order state must be immediately legible.
